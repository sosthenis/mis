Abrir a Matriz Hídrica IRP-PPP Digital

1. Acesso on-line

Clique no link acima ou use o QR code inserido no artigo. O acesso on-line funciona em computador, tablet ou telefone com conexão à internet.

2. Acesso off-line

Na pasta distribuída com o artigo, abra o arquivo Matriz_Hidrica_IRP_PPP_Digital_v1_0.html. O funcionamento local não exige instalação.

3. Funcionalidades

O protótipo permite cadastrar o projeto, preencher requisitos, registrar evidências, visualizar gates e alertas, filtrar a matriz, salvar dados no navegador, exportar ou importar JSON e imprimir relatório.

4. Salvamento e privacidade

O salvamento local utiliza o armazenamento do navegador. Para preservar uma cópia, utilize a função Exportar JSON. Não insira dados sigilosos, informações pessoais sensíveis ou documentos restritos em uma versão demonstrativa não homologada.

5. Limites

O protótipo não calcula score, Value for Money ou Public Sector Comparator; não seleciona automaticamente IRP ou PPP; não substitui pareceres especializados; não comprova viabilidade; e não constitui sistema institucional homologado.

6. Referência

TIMÓTEO, Sosthenis de Lima. Matriz Hídrica IRP-PPP Digital: protótipo demonstrativo de apoio à preparação decisória. Versão 1.0. Fortaleza: autor, 2026. 1 programa de computador (HTML, CSS e JavaScript).
